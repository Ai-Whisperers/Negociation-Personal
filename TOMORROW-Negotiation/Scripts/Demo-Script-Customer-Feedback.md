## DEMO DON'TS (Avoid These Mistakes)

❌ **Don't:** Spend 10 minutes on upload UI
✅ **Do:** Show it works in 30 seconds, move on

❌ **Don't:** Explain the technical architecture
✅ **Do:** Focus on business value (churn, pain points, ROI)

❌ **Don't:** Demo every single feature
✅ **Do:** Show the 3-4 features that matter most

❌ **Don't:** Use fake/trivial data
✅ **Do:** Use real 850-comment file (builds credibility)

❌ **Don't:** Apologize for limitations
✅ **Do:** Highlight what it does well

❌ **Don't:** Go into code or technical details unless asked
✅ **Do:** Stay focused on outcomes
