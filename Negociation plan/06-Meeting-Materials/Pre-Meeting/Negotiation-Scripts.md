## How to Use This Document

This document contains **word-for-word scripts** for every part of the negotiation meeting. You can:
- **Memorize** key sections (especially opening, pricing questions, and objections)
- **Read** during the meeting if needed (have it open on second screen)

**Color coding:**
- 🟢 **GREEN** = Ideal response / Strong position
- 🟡 **YELLOW** = Acceptable response / Moderate position
- 🔴 **RED** = Walk-away response / Final position
