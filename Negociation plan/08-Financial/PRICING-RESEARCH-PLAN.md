### 7. MAINTENANCE SCOPE DEFINITION (CRITICAL)

**Why This Matters:**
"3 fixes/improvements per month" is vague. You need clear boundaries or clients will abuse it.

#### Define Exactly What's Included:

**Included in 5-7M/month Maintenance:**
- [ ] **Hosting & Infrastructure:**
  - All Render.com services (4 services)
  - All API costs (OpenAI)
  - Database, Redis, email services
  - 99%+ uptime SLA

- [ ] **Support:**
  - Response time: ____ hours (business hours? 24/7?)
  - Support channels: Email? Phone? Slack?
  - Language: Spanish? English? Both?

- [ ] **3 Fixes/Improvements Per Month:**
  - **Definition of "Fix":** Bug resolution, no new functionality
  - **Definition of "Improvement":** Small enhancement, <8 hours of work
  - **Examples of what's INCLUDED:**
    - Fix: Incorrect emotion classification for specific phrases
    - Fix: Report generation failing for large files
    - Improvement: Add new chart to existing report
    - Improvement: Adjust email report schedule
    - Improvement: Translate new UI elements to Spanish
  - **Examples of what's EXCLUDED (requires separate quote):**
    - New major feature (e.g., sentiment tracking over time)
    - Integration with external system (e.g., Salesforce connector)
    - Custom dashboard design
    - Data model changes
    - Performance optimization for >10,000 comments

- [ ] **Updates & Maintenance:**
  - Security patches: Immediate
  - Platform updates: Monthly
  - AI model updates: As available
  - Feature updates: Quarterly

- [ ] **Reporting:**
  - Monthly usage report
  - Monthly performance metrics
  - Quarterly business review (QBR)

**What Happens If:**
- Client requests 5 improvements in one month?
  - Option A: Roll over 2 to next month
  - Option B: Charge additional fee per improvement (e.g., 1.5M per extra)
  - Option C: Hard limit of 3, excess go to backlog

- Client requests major feature (40+ hours work)?
  - Separate statement of work (SOW)
  - Quoted separately: 10-20M per major feature
  - Does not count against "3 improvements"

**Action:** Create a "Maintenance Terms" document defining all boundaries clearly.

#### **Pricing Option 1: Premium Development Model (Friend's Suggestion)**
```

  ├─ Includes: Setup, deployment, customization, training, go-live support
  └─ Timeline: 4-6 weeks

  ├─ Includes: Hosting, API costs, support, 3 fixes/improvements per month
```
