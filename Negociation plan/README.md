- **Target Range:** 60-80M PYG ($8,571-$11,429 USD)
- **Stretch Goal:** 100-150M PYG ($14,286-$21,429 USD)

### ROI Quick Facts
- **Their Pain:** $364,000/year + 40 hrs/month manual work
- **Our Solution:** $5,714-$11,429 one-time
- **Savings:** 97% cost reduction, 99.9% time savings
- **ROI:** 5,873% in year one
- **Payback:** <2 weeks

### José Luis's Top 3 Values
1. **Automation** - Eliminate 40 hrs/month manual work
2. **Daily/Weekly Reports** - Automated insights for executives

3. ✅ Quantified, urgent pain ($364k/year)
4. ✅ José Luis personally understands problem
