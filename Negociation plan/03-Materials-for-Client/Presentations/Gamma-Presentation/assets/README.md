## Image Specifications for Gamma.app

### General Guidelines:
- **Format:** PNG (for transparency) or JPG (for photos)
- **Resolution:** At least 1920x1080px for full-width images
- **File size:** Keep under 5MB per image for performance
- **Aspect ratio:** 16:9 for full-slide images

### Specific Recommendations:

**Logo:**
- Size: 500x500px minimum
- Format: PNG with transparent background
- Placement: Top left or center

**Screenshots:**
- Size: 1920x1080px (full HD)
- Format: PNG for sharp text
- Crop: Remove unnecessary UI elements
- Highlight: Circle or arrow key features

**Charts:**
- Size: 1200x800px minimum
- Format: PNG for sharp lines
- Colors: Match brand colors
- Labels: Large, readable text

## How to Add Assets to Gamma.app

### Method 1: Direct Upload
1. In Gamma editor, click slide
2. Click "Add element" → "Image"
3. Upload from this folder
4. Resize and position

### Method 2: Drag & Drop
1. Open this folder on your computer
2. Open Gamma in browser
3. Drag image directly onto slide
4. Gamma will upload automatically

### Method 3: URL
1. Upload image to cloud (Google Drive, Dropbox)
2. Get public link
3. In Gamma, "Add element" → "Image" → "From URL"
4. Paste link

## Backup Plan

If you don't have time to create all assets:
- **Use Gamma's built-in:** Gamma has stock photos and icons
- **AI generation:** Gamma can generate images with AI
- **Keep it simple:** Text and numbers can be powerful without images
- **Focus on demo:** The live demo is your most powerful visual

**Remember:** A clean presentation with fewer images is better than a cluttered one with low-quality visuals.
