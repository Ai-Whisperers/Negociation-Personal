# How to Create Presentation in Gamma.app

**Estimated Time:** 15-20 minutes
**Difficulty:** Easy
**Cost:** Free (400 AI credits included)

---

## Step-by-Step Guide

### Step 1: Access Gamma.app (2 min)

1. Go to **https://gamma.app**
2. Click **"Sign up for free"** or **"Log in"**
3. Sign up using:
   - Google account (recommended - fastest)
   - Email address
   - Microsoft account

**Note:** Free plan includes 400 AI credits (enough for this presentation)

---

### Step 2: Start New Presentation (1 min)

1. Click **"Create new"** button on dashboard
2. You'll see three options:
   - **Paste in text** ⭐ (Recommended - use this)
   - Generate with AI
   - Import a file

3. Select **"Paste in text"**

---

### Step 3: Paste Content (2 min)

1. Open **[presentation-outline.md](presentation-outline.md)** in this folder
2. **Select all** (Ctrl+A / Cmd+A)
3. **Copy** (Ctrl+C / Cmd+C)
4. Return to Gamma.app
5. **Paste** into the text box (Ctrl+V / Cmd+V)

**Tips:**
- Paste the entire outline (all 23 slides)
- Don't remove the markdown formatting (### headers, bullets, etc.)
- Gamma's AI will interpret the structure automatically

---

### Step 4: Configure Settings (1 min)

**Format Selection:**
- Choose: **"Presentation"** (not Document or Webpage)

**Number of cards/slides:**
- Gamma will auto-detect (~23 slides)
- You can adjust if needed

**Language:**
- Select: **"English"** (or Spanish if preferred)

**Click: "Generate"**

---

### Step 5: Choose Template (2 min)

Gamma will show several professional templates.

**Recommended Templates:**
1. **"Executive"** - Professional, clean, data-focused
2. **"Modern Business"** - Contemporary, bold colors
3. **"Minimal"** - Simple, elegant, less distraction
4. **"Corporate"** - Traditional business style

**Selection Criteria:**
- Choose template that feels **professional but approachable**
- Avoid overly colorful/playful themes
- Consider Personal Paraguay's corporate culture

**Preview each template**, then click **"Use this theme"**

---

### Step 6: AI Generation (1 min)

Gamma will now:
- Parse your content
- Create slide structure
- Apply design layouts
- Generate visuals
- Format text

**This takes 30-60 seconds**

---

### Step 7: Initial Review (3 min)

Once generated, review the presentation:

**Check:**
- [ ] All 23 slides are present
- [ ] Content is correctly distributed
- [ ] Headers are clear
- [ ] Data/numbers are accurate
- [ ] No formatting errors

**If issues:**
- Use **AI Edit** feature (bottom right)
- Ask AI to fix specific slides
- Regenerate specific cards if needed

---

### Step 8: Customize Brand (5 min)

#### Add Logo
1. Click **"Theme"** (top right)
2. Select **"Brand"** tab
3. Upload **AI Whisperers logo**
4. Position: Top left or center (your preference)

#### Set Colors
1. In Theme settings, find **"Colors"**
2. Set primary color: `#[Your brand color]`
3. Set secondary color: `#[Your accent color]`
4. Set text color: `#333333` (dark gray)

**Recommended Color Palette:**
- Primary: Professional blue (#0066CC)
- Secondary: Accent green (#00C853)
- Background: White (#FFFFFF)
- Text: Dark gray (#333333)

#### Set Fonts
1. In Theme settings, find **"Typography"**
2. Header font: **"Inter"** or **"Roboto"** (modern, clean)
3. Body font: **"Inter"** or **"Open Sans"** (readable)

---

### Step 9: Add Visual Elements (5-10 min)

#### For Slide 8 (ROI Numbers):
1. Click slide 8
2. Click **"Add element"** → **"Chart"**
3. Create bar chart:
   - X-axis: Status Quo, Enterprise SaaS, Build In-House, Our Solution
   - Y-axis: Cost ($)
   - Highlight "Our Solution" as winner

#### For Slide 11 (Comparison Matrix):
1. Gamma should auto-format tables
2. If not, click **"Add element"** → **"Table"**
3. Add checkmarks (✅) and X marks (❌) for visual clarity

#### For Slide 16 (Timeline):
1. Click **"Add element"** → **"Timeline"** or use icons
2. Show 2-week progression visually

#### General Visual Tips:
- Add **icons** where appropriate (click "Add element" → "Icon")
- Use **images** sparingly (only if you have relevant screenshots)
- Keep **text minimal** (Gamma handles this well already)

---

### Step 10: Refine with AI Chat (3 min)

Gamma has an **AI Chat** feature (bottom right).

**Use it for:**

**Example prompts:**
- "Make slide 8 more visual with a chart showing cost comparison"
- "Add more emphasis to the ROI numbers on slide 9"
- "Change the layout of slide 11 to make the comparison table clearer"
- "Make the 'Automation' benefit stand out more on slide 4"
- "Add transition effects between sections"

**Tips:**
- Be specific in your requests
- One change at a time
- Preview before accepting

---

### Step 11: Add Interactive Elements (Optional, 3 min)

#### Embed Demo Video
If you have a demo video:
1. Go to slide 7 (Live Demo)
2. Click **"Add element"** → **"Embed"**
3. Paste video URL (YouTube, Vimeo, Loom)

#### Add Clickable Buttons
1. Click **"Add element"** → **"Button"**
2. Text: "View ROI Calculator"
3. Link to: [Your Excel file URL or Google Sheets]

#### Add GIFs
For engagement:
1. Search Giphy integration in Gamma
2. Add subtle, professional GIFs (avoid distracting)

---

### Step 12: Practice & Timing (5 min)

1. Click **"Present"** mode (top right)
2. Walk through entire presentation
3. Time yourself: Aim for **15-20 minutes**
4. Note any slides that need adjustment
5. Practice transitions between slides

**Timing per slide (rough guide):**
- Slide 1-2: 1 minute (intro)
- Slide 3-6: 6 minutes (problem/solution)
- Slide 7: 5 minutes (demo)
- Slide 8-11: 6 minutes (ROI/comparison)
- Slide 12-20: 5 minutes (details/packages)
- Slide 21-23: 2 minutes (close)

---

### Step 13: Export & Share (3 min)

#### Export as PDF
1. Click **three dots (...)** menu
2. Select **"Export"** → **"PDF"**
3. Download and save to this folder
4. **Use for:** Printing handouts, backup

#### Export as PowerPoint
1. Same menu → **"Export"** → **"PowerPoint"**
2. Download and save
3. **Use for:** Compatibility, offline backup

#### Get Shareable Link
1. Click **"Share"** (top right)
2. Set permissions: **"Anyone with link can view"**
3. Copy link
4. **Use for:** Sending to José Luis or stakeholders

#### Export as Google Slides (Optional)
1. Export menu → **"Google Slides"**
2. Opens in Google Drive
3. **Use for:** If client prefers Google ecosystem

## Troubleshooting

### Issue: AI generated wrong structure

**Solution:**
- Use AI Chat: "Reorganize content into exactly 23 slides"
- Or manually split/merge cards (drag and drop)

### Issue: Text is too small/large

**Solution:**
- Click text box
- Adjust font size in toolbar
- Or use AI Chat: "Make all body text larger"

### Issue: Images/charts not appearing

**Solution:**
- Manually add via "Add element" menu
- Upload your own images
- Use Gamma's stock image library

### Issue: Colors don't match brand

**Solution:**
- Go to Theme → Brand
- Manually set exact hex codes
- Apply to all slides

### Issue: Ran out of AI credits

**Solution:**
- Free plan: 400 credits (should be enough)
- If needed, upgrade to Plus ($8/month) for unlimited
- Or export what you have and manually finish

### Issue: Can't export

**Solution:**
- All export options available on free plan
- Check internet connection
- Try different browser (Chrome recommended)

## Tips for Success

### Design Tips

1. **Keep it simple** - Less is more
2. **One idea per slide** - Don't overload
3. **Use white space** - Let content breathe
4. **Consistent colors** - Stick to 2-3 colors
5. **Professional fonts** - Avoid decorative fonts
6. **High contrast** - Dark text on light background

### Content Tips

1. **Numbers stand out** - Make ROI figures prominent
2. **Visuals over text** - Use charts, not paragraphs
3. **Highlight benefits** - Not just features
4. **Tell a story** - Problem → Solution → Value
5. **Call to action** - Clear next steps

### Presentation Tips

1. **Practice transitions** - Know what's coming next
2. **Prepare for questions** - Have backup slides
3. **Control pacing** - Don't rush through data
4. **Engage audience** - Ask questions, pause
5. **Have backup** - PDF on phone/tablet in case
