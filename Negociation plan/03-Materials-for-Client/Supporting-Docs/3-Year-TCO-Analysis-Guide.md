## Key Formulas

**ROI Calculation:**
```excel
=((Savings - Investment) / Investment) * 100
```

**Payback Period (Days):**
```excel
=(Investment / Annual_Savings) * 365
```

**Cumulative Cost:**
```excel
=SUM($B$2:B2)  // Drag down for running total
```

**Savings vs Status Quo:**
```excel
=Status_Quo_Cost - Option_Cost
```

**Net Present Value (NPV) - Optional:**
```excel
=NPV(discount_rate, year1, year2, year3) - initial_investment
```
*Use 10% discount rate for conservative analysis*
