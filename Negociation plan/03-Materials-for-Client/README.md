### How to Create Presentations

**Using Gamma.app (Recommended):**
1. Go to https://gamma.app
2. Click "Import" → "Paste text"
3. Copy content from chosen markdown file
4. Gamma will auto-generate beautiful slides
5. Customize colors, fonts, images
6. Export to PowerPoint or present directly

**Using PowerPoint:**
1. Use markdown as outline
2. Create slides manually
3. Add visuals and charts
4. Export to PDF for client

## Usage Guide

### Before Meeting (Oct 17)

**DECIDE ON FORMAT:**
- **10-slide deck:** Standard meeting, predictable timeline
- **2-part presentation:** Flexible, adjust based on interest level
- **Language:** English (José Luis is fluent) or Spanish (if others join)

**PREPARE:**
1. Choose format (recommend 10-slide for Oct 17)
2. Create slides in Gamma.app (30 minutes)
3. Review with team (Kyrian, Jonathan, Ivan)
4. Practice delivery (15 minutes)
5. Export backup PDF (in case of technical issues)

**TEST:**
- Demo product (ensure all features working)
- Screen sharing (test with team)
- Internet connection (backup hotspot ready)
- Presentation timing (stay within 15-20 min)

### During Meeting

**DEMO SCRIPT:**
- Jonathan leads demo (technical expertise)
- Kyrian frames business context ("This automation saves 40 hrs/month...")
- Ivan tracks time (signal if running long)

**PRESENTATION:**
- Keep to 15-20 minutes
- Focus on ROI and automation (José Luis's top values)
- Leave time for questions and discussion
- Use demo to SHOW, not just tell

**MATERIALS TO HAVE:**
- Laptop with demo loaded
- Backup demo (screenshots or video)
- Presentation slides (Gamma.app or PowerPoint)
- Backup PDF (if tech fails)

### After Meeting

**SEND FOLLOW-UP:**
1. Thank you email within 2 hours
2. Attach presentation slides (PDF)
3. Include demo video link (if recorded)
4. Offer to re-demo or answer questions

**CREATE PROPOSAL (If requested):**
1. Use chosen pricing tier (S/M/L or Pilot)
2. Include payment terms discussed
3. Add timeline and milestones
4. Include support and training details
5. Send within 24-48 hours
